# EAC 教育產品：由學習價值決定功能

2026-11-11；依用戶最新要求，參考範圍擴展至整套產品及教學方法，不限 UI／UE。此文件與 [UI／UE 路線圖](UI_UX_ROADMAP.md)、[題庫計劃](CONTENT_EXPANSION_PLAN.md) 分開維護。

## 本輪實際研究

- [Thinka 香港課程](https://www.thinka.ai/zh-HK/curriculum/hong-kong)：實際進入 HKDSE 數學 → ASGS 筆記 → ASGS 練習。筆記以概念、辨識、推導、例題、常見錯法、應用、快速檢查串起；練習頁公開 5 MCQ＋5 書寫題。實際選第一題 C（175），出現「答對了」、選項鎖定；展開解題步驟。另實際答錯第二題，頁面顯示正確選項並自動打開解法；屬提供標準推理，未見針對該選項的個人錯因診斷。書寫題先要求自己寫，再核對。公開頁把「看標準答案」與「批改學生自己的答案」分開，後者導向 app。
- [Thinka 教師／家長](https://www.thinka.ai/zh-HK/teachers)：公開定位是減少找題／批改重複工作，按課題難度生成工作紙，將結果用於下一次教學。班級分析、AI 長答批改及效果百分比是頁面宣傳，本輪沒有登入驗證其後端或成效。
- [Khan Academy](https://www.khanacademy.org/)：實際切換 Families 分頁，見到在家鞏固課堂、追蹤及參與、透過練習建立信心。首頁將 consistent practice → immediate feedback → teacher insights 放在同一學習循環，並分學生／家長／老師入口。未建立帳戶、未驗證 mastery 演算法或研究數字。嘗試直接讀 mastery 文章未載入正文，不納入已確認證據。
- [Brilliant 前輪觀察](EDUCATION_UX_REFERENCE_20261111.md)：以可操作視覺及清楚課題範圍降低開始門檻；本輪沒有新增登入體驗。

只取可核實的產品模式，不複製原題／圖像／品牌資產；不將競品廣告數字當作 EAC 成效。

## 為甚麼值得學，以及 EAC 要做甚麼

| 學習問題 | 產品方法 | 對學生／家長價值 | EAC 驗收條件 |
|---|---|---|---|
| 不知由哪裏開始 | 少量嘗試建立技能證據，再決定下一步 | 學生有明確小目標；家長知道安排原因 | 無記錄時不假稱弱項，已有記錄時有可追溯建議及真正可做的連結 |
| 看懂不等於會做 | 概念→例題→獨立作答→核對推理 | 避免「看過就當識」；家長可問第一步理由 | 閱讀、例題揭示、自評、客觀作答分開；不靠捲動自動授予掌握 |
| 做錯後只見紅叉 | 回看關鍵技巧及原解法，再做同技能不同題 | 知道修正方法，而非只累積題量 | 先提供真實錯題重練；之後加錯因、自我解釋及不同題驗證 |
| 進度數字誤導 | 顯示樣本、評核方式及資料範圍 | 家長理解實際做到甚麼、還缺甚麼 | 自動批改與書寫自評分開；明示最近結果與本機限制 |
| 家長只能問做咗幾題 | 易讀學習摘要＋下一步＋可問的問題 | 能支持思考，減少單看分數或施壓 | 學生可主動下載摘要，不自動發送，不假稱老師認證 |
| 老師找題耗時 | 同一題庫按技巧／難度組卷，結果回饋教學 | 題目針對需要，減省重複工作 | 現有組卷保留；下一步接待重溫技能，避免另建題庫副本 |

## 固定工作項目及狀態

| 編號 | 狀態 | 本輪結果／下一步 |
|---|---|---|
| EDU-01 | 完成（本機驗收） | 共用逐題最近證據彙整，Core／M1／M2 與課題隔離，自動／自評／舊不明記錄分開 |
| EDU-02 | 完成（本機驗收） | 八份現有導讀共享「作答證據→待重溫技巧→實際重練」入口；無記錄提供揀技巧，不捏造診斷 |
| EDU-03 | 完成（本機驗收） | 學生主動下載課題文字摘要給家長／老師，附資料限制、下一步及三個對話問題；不含姓名、電郵、原始作答 |
| EDU-04 | 待處理 | 保存每次作答、提示／解法是否已看、首次獨立答題與重做；現有 byQuestion 只夠最近結果，不能推進步趨勢 |
| EDU-05 | 待處理 | 錯因選擇與一句第一步理由，連結相應概念；需處理學生自述與老師判斷的區別 |
| EDU-06 | 待處理 | 不同題及隔日再測，按難度／來源／技能證據計算待驗證狀態；先定校準方案，不憑一次答對標掌握 |
| EDU-07 | 待處理 | 家長帳戶／同意／跨裝置資料及教師指派回收；需要後端與權限，不用本機下載假裝雲端平台 |
| EDU-08 | 待驗收 | 與真實學生／家長測試：能否講出下一步、理解自評與客觀批改差別、用摘要展開有效對話 |

推進順序：先讓現有可靠題庫形成「做→解釋→再驗證」循環，再擴資料模型與老師／家長協作；動畫負責引導與建立興趣，不能代替教學證據。新增大量題仍必須沿用既有來源、分類、圖像及數學 QA 流水線。
