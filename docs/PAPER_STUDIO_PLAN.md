## 第一版實際行為

入口：courses.html 與 library.html 的「我的試卷／組卷」，目的頁 papers.html。共用 QuestionBank compact index；預覽才按需載入原題，使用原有 EACMath 題面，不提前顯示解析。

一份卷使用一個課程、可跨多課題，最多 100 題；自動補入只用當前範圍未選題，不足時明示實際補入量。重複 ID 不允許；開始前解析 retired aliases，缺題、跨課程或合併後重複均阻止作答。

本機資料 key `eac_papers_v1`，version 1，papers 按 userId 隔離。每份保存 id、title、course、ids、userId、updatedAt，以及可選 minutes 和 marks（相容舊卷）；不複製題文答案。損壞格式不靜默覆寫。明確儲存，有未儲存離開提醒；不聲稱跨裝置同步、老師派卷或帳戶後端。

開始先儲存試卷，再建立現有 Learning session，保存 paperId 與指定題號順序；使用原 app.html?resume=1 作答。已有未完成練習時阻止覆寫，要求先返回續做。沒有另做評分引擎；本版不是正式限時考試。
