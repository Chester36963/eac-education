# EDU-UX · 教育網站觀察與 EAC 轉化

日期：2026-11-11。只觀察公開網站，不登入、交卷或複製題目／品牌資產；網站宣傳不當作已驗證能力。參考是產品模式及層級，EAC 保留炭黑封面、紙面、灰藍及已批准的立體書。

## 實際觀察

| 來源／範圍 | 實際見到／操作 | 對 EAC 的取捨 |
|---|---|---|
| [Thinka 香港課程](https://www.thinka.ai/zh-HK/curriculum/hong-kong) | 首屏以題面及回饋示例解釋產品；主次行動分開；課程階段分流；三步使用說明。實際展開「有沒有 DSE past paper」FAQ，確認漸進披露說明 | 首頁提供目標→課題→單一下一步，說明入口做甚麼。暫不聲稱 AI 批改、推薦已存在，亦不複製其練習題 |
| [Brilliant](https://brilliant.org/) | 首屏精簡角色入口、課題視覺；實際由 Algebra 切到 Calculus，標籤狀態與涵蓋範圍同步更換。頁面有視覺互動與學習計劃說明 | 模式切換同時改圖、說明與真正目的頁；示意圖服務於理解，不能只有動態裝飾。未登入評估個人化導師或 mastery 能力 |
| [DSE00](https://www.dse00.com/) | 公開首頁把 Past Paper、溫習工具等按學生任務放入導航，另有科目索引；主頁有資訊／討論密集區 | 借鏡任務命名，EAC 集中「學概念／練技巧／編試卷」，不照搬資訊密集、多支線的首頁 |
| [PaperKing 既有分析](PAPERKING_REFERENCE_REVIEW.md) | 沿用先前實際觀察記錄；本輪沒有重登入或驗證新功能 | 組卷沿用同一 canonical 題庫及已選範圍，不另建題目副本 |

以上為公開頁 UI 觀察，並非對其教育成效、批改正確率或後端能力的認證。沒有下載或加入第三方視覺資產。

## 效率規則

1. 課程、題庫與導讀用同一份生成資料；入口只保存 ID／URL 條件，避免重複寫課題清單。
2. 本次新元件限於 home-journey JS／CSS；開場在既有 exploration 模組內維護，不引入動畫套件或大型圖片下載。
3. 動態只用短時 CSS 與開場計時；不以自動輪播更換學生已選目標，不把正文預設隱藏。
4. 每輪先完成一個可走通任務，再驗四尺寸／減少動態／鍵盤／失敗回復；完成證據寫入 QA，而非只新增路線圖。
5. 匯入題庫及題圖 QA 保持獨立；本輪是 UI／UE 更新，新增題目為零。
