## 現有網站的具體問題

1. 舊色票、封面覆寫及練習功能各自使用海軍藍、粉紅、珊瑚、金色，沒有一個主系統。
2. UI 使用 EB Garamond，導覽、按鈕、次要資訊與展示標題缺少角色區分。
3. 原封面大標語壓過品牌，EAC 只在小導覽出現；圖形則像另一張獨立筆記封面。
4. 首頁索引有四個元素卻使用三欄、未明確指定位置，造成孤立連結與空白。
5. 邊框變數同時被當作「色值」及「完整 border」，部分邊框宣告失效。這是樣式一致性的實際原因之一。

## 實作規格

| 角色 | 規格 |
| --- | --- |
| 品牌封面 | #171819 炭黑；#F4F3F0 灰白字；#B6B6BA 輔助字；#414246 細線。 |
| 閱讀頁 | #FAFAFA 背景、白色輸入／選項；#202123 主字；#626469 次字；#DCDCDF 分隔。 |
| 強調色 | #762A32 深酒紅；只作小範圍標記，沒有金色 UI。 |
| 答題狀態 | 正確保留綠色、錯誤保留紅色；不能為品牌一致而消除學習語義。 |
| 字體角色 | 系統無襯線：導覽、按鈕、分類、說明。Cormorant／宋體後備：展示標題。EB Garamond：英文題幹及選項。MathJax：公式。 |
| 比例 | 展示封面可以大字；學習頁維持閱讀尺度，字級以固定斷點調整，字距為 0。 |
| 形狀 | 細線、平面章節列、小圓角；圖形不再包在帶投影的筆記卡中。 |
| 手機 | 縮短封面文字及圖形的間距，主要按鈕與瀏覽入口並排；圖形完整顯示，繼續向下能見課題。 |

`variables.css` 保留 legacy token 名稱以維持相容，但其值統一為新中性色。`site.css` 管品牌與共享版面；`journey.css` 管學習流程中的操作狀態；`library.css` 管目錄結構。移除重複的舊紙色封面覆寫，沒有再加另一張 patch stylesheet。
