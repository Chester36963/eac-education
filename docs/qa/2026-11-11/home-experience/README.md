## 實際完成

- 保留大型立體書、頁疊、書脊及3D翻頁。加入淡色幾何描線、書封／內頁描線、三階段標題、進度、暫停／繼續及滑鼠輕微視差。略過、Escape、重播、鍵盤循環與焦點回復可用；開場時背景 inert，關閉時恢復。
- 開場背景分頁取消計時 frame、CSS 暫停，返回由原進度繼續。減少動態設定直接展示內容，手動概念圖與目標入口可用。開場播放時底層概念演示不更新，避免重複工作。
- 首頁加入三個目標，連去所選課題的基本導讀／技巧題庫／組卷。示意圖及說明同步；語意為原生 radio，鍵盤可選，手機控制≥44px。
- 來源載入失敗保留直接入口。課程詳情短進場與焦點回饋，減少動態不播放。
- 八個已發布題庫與61課題導航仍分開表達。未新增題目／題目圖、未改學生 ID／進度，未改帳戶後端。

## 測試及視覺

- Node 全套：1,136 passed，0 failed。
- home-experience：開場暫停／繼續及進度、背景 inert／焦點／Escape／重播；320／390／768／1440 × 三目標；對應課題 URL 及實際組卷交接；減少動態與失敗後備入口。
- 背景停止另以模擬 document visibility 事件核對進度凍結／恢復；不等同實體裝置背景分頁效能測量。
- exploration：原有四尺寸三頂點拖動、四心與外接圓關係、預設、演示、單位圓及函數、翻書及 reduced-motion 回歸通過。課程詳情／搜尋／課程隔離回歸通過。
- 概念插圖為本網站原創，不是來源題圖：書頁二次函數逐點核對 y=x²−1；目標入口等邊三角形頂點與外接圓距離49、內切圓半徑24.5；等差序列 Tn=2n+1 的前四項3／5／7／9。原有四心及正弦幾何由既有模型生成。
- 桌面／手機開場及目標入口、新概念 SVG 獨立畫面已視覺檢查；修短書頁標頭，避免跨到書脊。沒有 PDF，不能把此輪概念插圖檢查當作新增題圖驗收。

尚未驗證：真實學生任務完成時間、實體 iOS／Android 流暢度、整站內頁互動改造。沒有聲稱完成 AI 批改或跨裝置同步。
