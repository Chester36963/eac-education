## 實際修改

- UX-N04：A、B 的 x／y 各自可在 −3 至 3 調整，可直接拖動、觸控或方向鍵移動；Shift 加速。兩點最短距離0.5，避免重合使構作未定義。
- OP=r 保留半徑和角度。PA=PB 顯示垂直平分線及相等距離；追蹤範圍 t 只控制 P 的示範位移，不是把完整軌跡限制成線段。PA⊥PB 顯示直徑圓、直角標記及空心端點；P 到達 A 或 B 時不顯示合法 P，明確說明端點排除。
- 圖框等比例容納垂直、水平及斜向構作，拖動時固定座標映射避免圖形追着手指跳動，放開後再適配。座標成對排列，模式只顯示相關控制。
- 手動操作暫停；模式／課題切換保留當次狀態，重設目前模式。自動播放會改變兩點的二維座標，離屏暫停，回來繼續。減少動態預設靜止。
- 語言切換保持既有配色，點按高度增加至44px。五個共用樣式／程式資產以內容hash更新所有引用入口，含封面與設定；`node scripts/version-study-assets.cjs` 更新、`--check` 驗證，單元測試會防止遺漏。
