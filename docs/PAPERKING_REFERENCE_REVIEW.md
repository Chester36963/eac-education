## EAC 應採用及提升的體驗

- **逐步選擇＋即時摘要**：範圍與技巧 → 題型與份量 → 預覽與開始。桌面側欄摘要；手機收合摘要及底部主要操作。保留條件，不足題數明確提示，不默默換技巧湊題。
- **練習是可重用物件**：保存題目ID／次序、條件、語言及內容版本；作答紀錄另存。續做恢復原位置；重做新增 attempt，不覆寫原成績。內容改版需提示，沒有快照不承諾還原歷史題文。
- **學生／教師分工**：學生顯示開始溫習、題庫、我的練習、錯題／收藏；教師才顯示組卷、試卷、班級、批改。本機來源工作台維持本機，不與教師入口混淆。
- **網上與列印分開**：網上保留題號導航、未答狀態、續做及交卷前提醒；A4只用於列印。參考網站的整卷長頁不是所有學生最合適的作答方式。
- **結果有下一步**：解答 → 待重練技巧 → 重做錯題；自動評分、書寫自評與教師評分清楚區分。報告必須可追溯至實際作答，不憑少量紀錄猜掌握率。
- **視覺保持 EAC**：炭黑封面／翻書、紙面、灰藍、統一中文無襯線與數學字體。用字級、細線、間距、操作回饋建立層級。動畫集中導航及教學探索。避免參考站卡通機械人、大型宣傳橫幅、多色漸層、金色／綠色主題。

## 接力工作與驗收

以下是待實作規格，不能由參考分析推論已完成。

| 編號 | 狀態 | 交付與驗收 |
|---|---|---|
| PK-01 | 待處理 | 盤點現有組題、歷史、續做與收藏，定共用練習集模型，保留穩定ID／舊紀錄。以ASGS示範，沿用現有題庫架構。 |
| PK-02 | 待處理 | 三步組題與即時摘要；返回／刷新恢復條件，空結果、課程隔離、題數不足明確處理。鍵盤可走完整流程，觸控44px。 |
| PK-03 | 待處理 | 我的練習：儲存、搜尋、續做、重做及同條件再組。每次重做獨立紀錄；本機保存清楚標示，不以登入外觀冒充雲端同步。 |
| PK-04 | 待處理 | 共用預覽／列印，題目與解答分開、題號一致、多圖與A–D完整。按既定圖像QA檢查實際輸出，不能把螢幕版直接縮成難讀A4。 |
| PK-05 | 待處理 | 真實帳戶與教師工作區：先定身份、機構／班級權限、伺服器儲存及遷移，再實作名冊、派卷、截止／提交狀態。公開靜態JSON不能承擔私密紀錄或受保護試卷。 |
| PK-06 | 待處理 | 逐題批改、分數修訂紀錄、評語、發還及可追溯報告；待批改不當錯題，自評與教師分數分開。兩種角色完整端到端驗收。 |
| PK-07 | 待處理 | 教材沿用本機來源流水線；教師上載／AI草稿需來源、數學、圖像及發布審核。A/B等值卷與難度改編另列後續，不能只換數字就當等難度。 |
